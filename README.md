# Menu Tidy

一个使用 SwiftUI 与 AppKit 开发的 macOS 菜单栏整理工具。可以在列表中选择显示方式，也可以按住 ⌘ 直接拖动菜单栏图标分组，再通过「···」展开或收起。

[下载发布版本](https://github.com/cyruss648/menu-tidy/releases) · [使用与开发文档](docs/README.md) · [反馈问题](https://github.com/cyruss648/menu-tidy/issues)

> **macOS 27 兼容性限制：** 菜单栏空间不足时，普通展开仍可能无法显示全部图标，需要手动打开系统溢出入口。分组移动成功不代表突破屏幕容量限制；当前版本适合了解这些限制后试用。

## 主要功能

- 在列表中搜索应用，将图标分为三类；修改先保留为草稿，点击「应用并收起」后生效。
- 进入「在菜单栏拖拽分组」，按住 ⌘ 使用 macOS 原生拖动，完成后验证并保存分类。
- 菜单栏「···」切换普通展开／收起，右键打开管理菜单。
- 临时展开全部分组，随时在列表中找回或修改隐藏项目。
- 保存具备稳定标识的图标规则；支持自动收起、启动时收起和登录启动设置，默认均关闭。
- 使用系统应用图标展示列表，不申请屏幕录制权限。

下表描述**预期分组行为**。实际显示仍受 macOS 菜单栏空间限制。

| 分类 | 普通收起 | 普通展开 |
| --- | --- | --- |
| 常驻显示 | 本应用不主动隐藏 | 本应用不主动隐藏 |
| 收起后隐藏 | 收起对应分组 | 展开对应分组 |
| 始终隐藏 | 保持收起 | 保持收起，可通过「临时显示全部」查看 |

## 安装

需要 **macOS 13 或更新版本**。部署目标不等于所有系统版本均已完成实机验收；架构、签名、公证状态和预发布标记以 [Release 说明](https://github.com/cyruss648/menu-tidy/releases) 为准。

GitHub 发布提供 Apple Silicon（`arm64`）与 Intel（`x86_64`）独立安装包。**当前为预览版，使用项目专用自签名证书，并非 Apple Developer ID，尚未公证。**

1. 下载与 Mac 架构对应的发布包，解压得到 `Menu Tidy.app`。
2. 将应用放入 **应用程序**文件夹后打开，避免从临时解压目录反复启动不同副本。
3. 更新时先退出旧实例，再替换应用。签名身份或安装位置变化后，macOS 可能要求重新授权。

如果系统阻止首次打开，请先核对下载来源与 Release 的签名说明，再使用 macOS 提供的允许打开入口。不要关闭系统安全保护来绕过提示。

## 开始使用

1. 先退出 Barbee、Bartender、Ice 等其他菜单栏整理器。
2. 在 Menu Tidy 中点击 **申请辅助功能权限**，按系统提示开启当前安装副本的权限。
3. 返回应用，等待自动检测；也可点击 **重新检测**和**刷新图标**。
4. 在列表中选择分类并点击 **应用并收起**，或使用下面的 **在菜单栏拖拽分组**。列表自动应用期间请暂时不要操作鼠标或键盘。
5. 日常使用「···」切换普通分组；需要恢复隐藏项目时，右键打开管理界面，或再次打开应用。

### 在菜单栏拖拽分组

1. 右键点击菜单栏「···」，选择 **在菜单栏拖拽分组**（管理界面也提供入口）。菜单栏只在整理模式中显示「常隐」「收起」两个标记，全部分组保持展开。
2. 按住 **⌘ Command**，直接拖动菜单栏中的图标。分组取决于图标与两个标记的相对位置：

   | 图标位置 | 对应分组 |
   | --- | --- |
   | 「常隐」左侧 | 始终隐藏 |
   | 「常隐」与「收起」之间 | 收起后隐藏 |
   | 「收起」右侧 | 常驻显示 |

3. 松开 ⌘ 和鼠标，点击 **完成并收起**；也可点击菜单栏「···」或从其右键菜单完成。应用只保存连续两次可信扫描确认的分类，未知位置不会被猜测为某一组。

完成后，菜单栏根据实际标记位置启用隐藏区域；手动放在「常隐」左侧的区域随之保持收起，普通展开不会展开该区域。整理期间暂停列表分类、应用并收起和临时显示操作。选择 **保持展开并退出** 会保留已拖动的位置，并让全部分组保持展开，不会撤销拖动。

### 临时查看隐藏项目

从菜单栏菜单选择 **临时显示全部**，直接展开本应用的分组，**不自动打开管理窗口**。结束临时显示会恢复进入前的展开／收起状态。空间不足仍需通过系统溢出入口查看；「始终隐藏」不会退出应用，也不是隐私保护，手动完全展开系统溢出区仍可能看到这些图标。

应用还提供 `Control + Option + M` 切换普通分组，以及 `Command + Return` 应用当前选择。这两个快捷键尚未完成稳定的实机验收，遇到无响应请使用界面按钮。

## 权限与常见限制

**辅助功能权限**用于读取菜单栏项目、执行原生 ⌘ 拖动并验证位置，必须由用户在系统设置中开启。macOS 27 的相关页面可能显示为「设备控制和数据访问」。应用不能绕过系统确认；列表图标来自应用文件，不读取菜单栏截图。

如果系统开关已开、应用仍显示未授权，请在权限页展开「已开启仍未识别？」，按指引移除过期条目，再添加当前安装副本。持续本地开发可使用[固定本地签名身份](docs/LOCAL-SIGNING.md)减少身份变化。

- **目前仅扫描主显示器。** 多显示器、全屏、睡眠恢复和登录启动尚未完成实机验收。
- **系统空间不足仍会溢出。** 刘海屏、较多图标和前台应用菜单都影响可见容量；当前没有第二行菜单栏或独立图标面板。
- **部分项目不能移动或持久保存。** 系统保护项不可分类；缺少唯一稳定标识的图标仅在当前运行期间记住规则。
- **自动收起不完整追踪第三方下拉菜单。** 指针移出菜单栏后，仍可能达到设定的收起时间。
- **错误会保留未完成选择。** 已验证的项目保存，其余保持待应用；未知几何不当作移动成功。

详细的已验证项目、已知问题和测试范围见[验收文档](docs/README.md#验收记录)。

## 从源码开发

项目使用 Swift 6 与 Swift Package Manager，没有第三方 Swift 包依赖。在 macOS 上安装 Xcode 或 Command Line Tools、Python 3.11+、Git、`pre-commit` 和 `git-cliff` 后：

```sh
git clone https://github.com/cyruss648/menu-tidy.git
cd menu-tidy
./scripts/dev-setup.sh
./scripts/check.sh --full
./scripts/build.sh release
```

应用输出到 `dist/Menu Tidy.app`。`dev-setup.sh` 检查依赖并安装本仓库 Git hooks，不自动安装软件或创建签名证书。

开发安装、签名和提交约定见[开发指南](docs/DEVELOPMENT.md)，自动发布与签名配置见[发布指南](docs/RELEASING.md)。历史验收记录保留在 `docs/`，不会将构建通过替代功能验证。
