# 图标缺失与无弹窗动作处理

目标版本：0.7.29（build 105），stable 通道。

## 行为与修复

应用进程仍在运行不代表它当前提供菜单栏图标。用户在应用内关闭该图标后，普通扫描确认没有可用图标的记录移入“离线与保留记录”，显示“当前无菜单栏图标 · 原分类”，不计入当前图标或参加批量操作。分类、规则及草稿继续保留；不会把进程误判为已退出，也不会仅凭图标缺失断言用户关闭了开关。

读取连接确实失败时，主列表仍保留重新连接入口。macOS assessment 已确认隐藏、只是暂时移除 AX 节点的图标继续保留清单，避免把 Menu Tidy 自己隐藏的图标误判为离线。

同一进程重新启用图标时，旧的成功连接尝试不再阻止重新应用保存的分类。仅在普通扫描确认整个应用清单消失、所有者仍有效且没有真实读取或分类失败时，允许开启新的连接周期；失败重试限制不变。按应用保留的记录也不会再重复显示对应的旧来源规则。

托盘原生动作未出现新菜单或窗口时，取消此前“已发送一次后台操作，但未确认新菜单或窗口”的黄色提示。这种结果仍记录在诊断日志，不宣称已打开菜单，也不追加点击。动作被拒绝、权限不足、恢复隐藏失败等真实问题继续提示。界面仍可见或无法完整读取时，继续保护临时显示状态；只有确认没有活动界面或原进程已退出时才继续恢复。

这项行为适用于第三方应用自身的原生点击语义，没有为 Snow Shot 添加应用名称特例，也没有将其能力固定为“没有菜单”。
