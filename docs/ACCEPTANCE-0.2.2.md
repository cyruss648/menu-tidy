# Menu Tidy 0.2.2 实机验收

版本 0.2.2 (4)，2026-09-23，macOS 27.0 (26A428)，arm64，内置主屏。

## 安装与回归

用户明确要求安装至默认应用程序目录，并操控电脑测试功能。

- 默认安装位置已改为 `/Applications/Menu Tidy.app`；从该路径实际启动，应用权限卡显示同一路径。
- 原 `~/Applications/Menu Tidy.app` 移至 `~/Library/Application Support/Menu Tidy/Backups/Menu Tidy-user-install-20260923-095600.app` 保留，避免重复打开旧副本。后续更新同样先备份现有目标。
- 保留用户原偏好（包括原先开启的启动收起）；本轮未修改任何真实第三方图标分类。
- Release 构建、arm64 架构、严格签名校验通过，固定证书要求与 0.2.1 一致。未把签名完整性当作 TCC 授权连续性证明。
- 修正三状态项的容量计算：现代分隔区现为 28pt 入口 + 20pt 另一边界 + 4pt 余量预留 52pt。771.5pt 可用区中，自身三项宽度由 787.5pt 降至 767.5pt。此算术修复不等于系统实际隐藏行为已经通过。
- 35 个核心测试通过。32pt 最小边界仍保留，极窄区域不足 80pt 时不保证所有自身项目容纳；外部图标、全屏与多显示器仍需实测。

只修改并请求恢复 Menu Tidy 自身的授权，没有修改其它应用的隐私开关。系统的身份认证必须由用户本人完成，测试不能绕过认证或伪造授权成功。

后续顺序：完成授权 → 确认当前应用读取真实图标 → 临时显示全部并确认入口可操作 → 对单个非关键图标逐项测试收起隐藏、始终隐藏、恢复常驻 → 恢复原分组和偏好 → 验证重启／同证书更新后的权限状态。测试失败应先恢复可见性并保留窗口，不继续扩大变更。
