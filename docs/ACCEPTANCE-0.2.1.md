# Menu Tidy 0.2.1 验收记录

版本：0.2.1 (3)。日期：2026-09-23。环境：Apple Silicon arm64，macOS 27.0 (26A428)，主屏内置显示器。

## 本次故障与修复

用户反馈系统设置的授权已开启，应用仍显示未授权；同时要求菜单栏入口改为省略号。

实机确认旧版本进程运行在 `~/Applications/Menu Tidy.app`，系统设置「设备控制和数据访问」中的 Menu Tidy.app 开关为开启。09:29 的 `tccd` 日志记录 `Failed to match existing code requirement`：旧授权要求的 cdhash 前缀 `ff269cc8` 与当前安装应用 `d4c69771` 不同。因此 AX 返回未授权是系统的实际判断，刷新界面不能修复旧签名记录。

- 增加稳定本地开发证书签名，要求同时固定 bundle identifier 与证书，不修改系统信任；首次升级须重新添加当前安装副本的授权。
- 手动重新检测显示明确结果；权限卡可展开旧授权恢复指引，显示当前应用路径并提供访达定位。
- 主菜单栏入口固定使用 `ellipsis`，两个分组定位项保留布局和 AX 标识但不绘制竖线。
- 修复 macOS 27 MenuBarAgent 远程托管元素的原属应用识别，以实际 AX PID 和本轮运行进程快照解析；仅对同 PID、同启动时间、同 frame 且 app/host 来源和角色互补的投影去重。
