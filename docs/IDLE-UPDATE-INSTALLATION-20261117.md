# 空闲自动安装与重新打开

已发布版本：0.7.30（build 106），stable 通道。

## 行为

此前自动下载只安排正常退出时安装。新版增加独立、默认关闭的“空闲时自动安装并重新打开”选项，需要同时开启自动检查与自动下载。

Sparkle 完成下载与验证后，更新控制器保留官方 `willInstallUpdateOnQuit` 的安装回调，并返回 `true` 接管安装时机。Menu Tidy 连续空闲 5 秒后调用回调，安装与重新启动由 Sparkle 完成。空闲指本应用的菜单栏操作结束、托盘和右键菜单已关闭、桌面未锁定，也没有未完成的图标恢复；不是整台 Mac 无人操作。

安装前仍由 `AppDelegate.applicationShouldTerminate` 等待 `MenuTidyModel.prepareForTermination()` 完成正常图标恢复。恢复失败会拒绝退出、暂停自动尝试并保留手动重试入口。再次安装前需先解决恢复问题，不形成自动退出循环。关闭空闲安装不撤销 Sparkle 已安排的退出时安装。

新选项适用于开启后新下载并验证的更新。若更新已交给 Sparkle 安排退出安装，再开启此选项无法重新取得该安装回调；该次更新仍可从“检查更新…”安装，或等待正常退出。

旧版 0.7.29 及更早版本必须先用现有更新器安装一次新版，随后才能开启新选项。发布新 feed 不会改变正在运行的旧版代码。
