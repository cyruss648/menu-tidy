## 判定边界

32 个核心测试覆盖规则及状态，不操作系统隐私开关、鼠标、第三方菜单栏或登录服务。构建与 `codesign --verify --strict` 仅证明对应检查通过，不等于授权、移动、隐藏、运行架构以外的平台兼容性或公证通过。

运行期规则按项目分别接受：移动后连续两次读取 AX 顺序符合所选分类，才保存该项；具有稳定身份的已接受规则才写入长期偏好设置。失败时临时显示全部并保留未完成草稿。当前扫描只取主屏区域，多显示器尚未验证。

刷新必须暂时展开边界来读取位置，因此可见变化本身不算分类丢失。列表使用应用图标而非实际菜单栏截图；视觉预览和演示项目不替代 B05–B07 的真实跨应用验收。

## 本轮 GUI 证据

- 使用原生 UI 自动化检查并截图确认：900×740 管理界面、三类分组、权限三步指引、未授权空态、搜索／筛选入口、待应用按钮以及 Barbee 冲突提示均可见。
- 「权限与设置」页可访问，旧版用户偏好保留（本机已有的启动收起开关为开启；没有重置它）。
- 点击「打开系统设置」确实跳转到 macOS 27 的「设备控制和数据访问」页面，列表含 Menu Tidy.app，开关为关闭。界面文字已适配这一实际名称。
- 尚未替用户开启权限或退出 Barbee；已请求授权进行下一步实机测试。B02 的授权后自动刷新、B03 和 B05–B13 等依赖授权的测试仍未通过或未执行。
- 该版本没有请求屏幕录制权限，没有用应用图标缩略图或离屏预览代替真实菜单栏移动证据。
