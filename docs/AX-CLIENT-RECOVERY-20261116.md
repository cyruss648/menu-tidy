# 菜单栏读取连接异常恢复（2026-11-16）

## 现象与定位

本机已安装的 0.7.24（build 100）在登录后将搜狗输入法列为“等待发现图标”，但搜狗自己的菜单栏图标实际可见。管理窗口刷新没有消除该状态，保存的“收起后隐藏”选择仍在。

锁屏前的现场检查得到以下证据：

- 旧 Menu Tidy 进程的辅助功能总授权检查为真，但读取搜狗应用的 `AXExtrasMenuBar` 返回 `AXError.apiDisabled`（`-25211`）；其模型快照和 AX 扫描缓存都没有该图标。
- 独立启动的同签名观察进程能读到同一个搜狗进程及其启动时间，对搜狗自己的 `AXExtrasMenuBar` 完成直接子项枚举。该图标的角色为 `AXMenuBarItem`，几何有效、重复读取稳定，中心命中原始元素。
- 临时诊断还分别通过目标应用扫描和正常合并扫描读到了该搜狗图标。搜狗只有一个对应的运行进程，不能用系统输入法菜单代理中的另一枚图标解释这次差异。临时扫描诊断代码已移除。
- 启动日志显示既有启动重连已重试，并最终记录 `holdVisible=true`；后续持续发现也没有让旧进程读到该图标。

这些证据说明本次故障包含**当前 Menu Tidy 进程的 AX 读取被拒绝，而新客户端可以读取**。它没有证明 macOS 内部权限缓存的具体成因，也没有证明所有“等待发现图标”都属于同一种故障。普通图标迟到、应用没有创建状态项、AX 不支持该属性不满足连接恢复条件；后续对普通缺失状态的处理见文末补充。

2026-11-16 09:49:44（Asia/Shanghai）后桌面进入锁屏状态。锁屏后的命中失败和不可用读数不用于证明锁屏前的故障。

## 修复行为

扫描器按应用 PID 与启动时间报告 `apiDisabled`，模型将它与“未发现图标”区分。保存了隐藏分类、应用仍在运行且未被发现的条目会显示“读取连接异常”，并提供“重新连接”。界面保留原来的分类；原始错误码只在诊断中使用。

对同一应用进程连续三轮读到该错误后，在启动补偿结束、桌面可用且没有管理窗口或托盘交互时，执行一次独立核验：

1. 使用当前应用包中同一份签名可执行文件，以 `--check-menu-bar-owner` 运行独立的单次只读观察。子进程有四秒外部截止时间，输出只保留判定所需的结构字段。
2. 要求唯一的目标进程及相同启动时间、完整的原始直接子项清单、正确 owner 和父子关系、有效菜单栏角色、稳定几何及正向中心命中。核验不会为主扫描器注入元素身份、坐标或操作许可。
3. 返回后再次核对桌面会话代次、目标进程、当前扫描结果及交互状态；若正常扫描已经读到图标，取消恢复。
4. 确认新客户端能读到图标而旧客户端持续失败后，先持久化本次开机的自动恢复预算，再走 Menu Tidy 既有正常退出及恢复路径。独立交接进程确认原进程结束后，重新打开同一个应用包，重建 AX 客户端。

这是**正常重新打开应用**来重建连接，不是声称某个 AX API 可以原地重置连接。交接进程不终止原进程；正常退出被拒绝或未在二十秒内完成时，它放弃重新打开。直接在退出回调前保存预算，避免 `.terminateNow` 提前结束进程而导致重复自动恢复。

每次系统开机最多自动交接一次，跨 Menu Tidy 进程保留该限制。独立核验失败时，同一失败阶段不反复启动检查进程；错误消失、图标重新出现或目标进程更换后重新计算。用户可以在管理窗口主动重新检查；主动检查成功后会重新打开管理窗口。

锁屏、会话切换、目标进程退出或更换、普通 AX 空值和不支持属性、独立核验失败，以及正在进行的分类和托盘操作，均不会授权自动重新打开。

## 应用内关闭菜单栏图标的补充修复

用户明确说明：邮箱大师的菜单栏图标是主动在该应用设置中关闭的。因此，没有该图标是正常状态，不应长期显示橙色“等待发现”并计入“尚未完成”。先前 `AXError.noValue` 的现场结果与此相容；但仅凭 AX 空值不能推断任意应用的具体设置。

补充修复采用以下行为：

- 对有已保存分类、正在运行但没有可操作菜单栏来源的应用，显示灰色“当前无图标”，说明“当前未读到菜单栏图标，可能已在应用内关闭。分类已保留，图标出现后会自动接回。”
- 普通缺失不产生待应用任务，不计入“尚未完成”和“需要处理”，不进入批量应用或失败重试，不触发连接恢复或重启。原三种分类均保留，应用未运行时仍进入离线记录。
- 明确的 `apiDisabled` 继续显示连接异常并计入需要处理；后续只读扫描返回普通空值时清除此异常状态。
- 启动期仍使用原有有限次数的发现。超过该窗口后按原有 60 秒间隔只读检查；普通刷新发现保存过分类但尚无图标的进程，也会登记该低频检查，不依赖一定收到应用启动通知。重复扫描不推迟截止时间，成功发现或精确进程退出后撤销检查。
- 在同一进程内重新开启图标后，沿用正常发现和身份核验路径接回原分类；不会操作邮箱大师自己的图标开关。
