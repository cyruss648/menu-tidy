# 文档索引

日常安装与使用从[项目 README](../README.md)开始。发布包、架构及签名信息以 [GitHub Releases](https://github.com/cyruss648/menu-tidy/releases) 的对应版本说明为准。

当前开发版的日常流程是 **常驻菜单栏 / 收进托盘** 二选一，选择后自动执行单项设置。点击菜单栏箭头打开六列独立托盘，首帧使用有效原图缓存或明确的应用身份图标；屏幕录制为可选增强。三分组、草稿关联、批量应用和原图采集保留在高级兼容维护中。当前交互合同、实现边界与实机证据以[独立托盘体验](TRAY-EXPERIENCE.md)为准。

[交互与执行流程评审](INTERACTION-REVIEW.md)记录上一阶段对批量分类、刷新、时间预算和恢复的重构。其历史结果不改写；主界面、启动连接、图像权限及日常使用合同由新的托盘文档补充，不能把旧文档中的“草稿 → 应用”或“原图必需”当作当前主流程。
