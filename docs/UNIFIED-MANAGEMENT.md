# 统一图标管理页：交互设计与代码审查

日期：2026-09-29。对应 0.6.0 / build 53 的源码改进，公开发布状态以 GitHub Release 为准；0.5.0 / build 52 的已发布功能和历史实机证据不作为本次改动的验收结果。

## 设计判断

“高级兼容维护”不是完全失效的功能。它仍承载三分类、列表刷新、批量应用、旧草稿关联与兼容模式拖拽，但与主列表重复；两处分别要求立即执行和应用后生效，令同一图标出现两套操作解释。应合并当前操作，保留历史记录及必要恢复能力。

本轮先在正在运行的正式应用中进行只读观察与截图，确认了两态主列表、隐藏较深的高级入口、旧草稿数量，以及普通应用“窗口 / 帮助”被列为图标的实际现象。未在正式应用中执行分类、批量重试、规则删除或权限变更。

## 页面与场景

| 场景 | 入口与交互 | 状态规则 |
| --- | --- | --- |
| 日常更改一个图标 | 每行固定三项：常驻显示、收起后隐藏、始终隐藏 | 立即保存并排队；实际验证通过才确认结果 |
| 快速反复更改 | 不必等待上一次操作结束 | 最新选择覆盖等待中的旧选择；活动操作先完成清理 |
| 多个未完成项 | 顶部固定“应用全部待处理”与数量 | 覆盖所有可直接应用的未完成项，包括失败项；搜索不改变批量范围 |
| 多个失败项 | 顶部固定“重试失败项”与数量 | 只重试真实失败项，保留三态；失败不自动循环 |
| 身份需要单独确认 | 行内“识别并连接”与明确说明 | 批量操作跳过；不能猜测身份或按名称关联 |
| 查找项目 | 搜索、分组卡、全部 / 三分类 / 需要处理筛选 | 卡片按在线图标当前选择统计，不宣称为成功隐藏数量 |
| 重新读取状态 | 搜索栏旁“刷新”，快捷键 ⌘R | 保留选择，不重试同一进程已失败的操作 |
| 临时访问始终隐藏项 | 更多菜单“临时显示全部” | 普通托盘不含始终隐藏；显式全部显示才加入 |
| 原图更新 | 更多菜单“更新原始图标图像” | 独立于显示设置；采图失败不抹掉已确认分类 |
| 应用退出或旧会话身份不明 | 底部“离线与保留记录” | 不参与批量操作；旧草稿需要明确关联，关联后仍待应用 |
| 忘记已退出应用 | “忘记此应用…”及删除范围确认 | 清除该应用离线规则、应用级选择和草稿；有在线同应用图标时不可执行；恢复账本保留 |
| 权限缺失、未完成恢复 | 主列表前方显示对应卡片与恢复入口 | 不把通用重试当作授权或恢复；暂停冲突操作 |
| 操作中停止 | 原有固定进度区与停止按钮 / Esc | 丢弃尚未开始的工作，等待当前改动清理；已确认结果保留 |

视觉上沿用现有原生窗口、青绿色强调色和圆角卡片：固定批量操作区、三张分类概览、单一列表，减少重复标题与大块维护说明。保留文字状态、原因与按钮，不仅用颜色传递结果。三项分段控件提供逐图标辅助功能名称，系统保护项明确禁用。

## 代码审查与修复

| 问题 | 修复方式 |
| --- | --- |
| 重试通过 Bool 把始终隐藏降为普通隐藏 | 队列与请求完整保留 `ItemVisibility`，重试读取原三态 |
| 普通托盘忽略始终隐藏分类 | 使用明确面板成员策略，区分普通展开与显式显示全部 |
| 同应用多个图标的旧草稿和选择互相冲突 | 对当前唯一身份的兄弟图标原子准备草稿，保存成功后更新应用级选择；共用串行操作与处理中状态 |
| 成功后仍留下重试错误 | 仅在确认结果匹配最新选择时清理过期错误 |
| 失败共享开关可能随兄弟图标重复尝试 | 同一批次对共享目标按尝试去重；未托管的常驻图标仍逐个取得可见证据 |
| 普通应用主菜单被误当作状态栏图标 | 通过所属应用的 canonical `AXMenuBar` 根与 `CFEqual` 排除其子树，不按标题、语言或坐标猜测；隐藏项连续性保留仍需精确证据 |
| 忘记规则后应用级选择重新生效 | 在无在线同应用图标且 bundle 精确匹配时，清理对应应用级选择与离线记录 |
| 明确关联的旧草稿被已有应用选择覆盖 | 关联时同步明确的应用级意图与当前兄弟草稿，继续保留为待应用 |

## 验证方法与边界

最终 `scripts/check.sh --full` 通过：warnings-as-errors 编译、458 项 Swift 测试、80 项 Python 测试及源码门禁。独立复审发现的问题完成修复并再次检查，未发现剩余阻断级问题；AX 根过滤由根任务另行核查。

真实 SwiftUI 模拟窗口验证了三项即时切换、卡片筛选、仅重试失败项、筛选外待办的统一应用、完成空状态、离线记录保留、删除范围确认及缺权限时禁用操作。预览使用独立 `dev.hdh.MenuTidy.preview` 包、独立模拟设置与内存条目；不加载真实恢复日志、不创建菜单栏项、不注册全局快捷键、不启用更新，也不触发原生显示改动。

构建预览：

```sh
./scripts/build-ui-preview.sh
open -n "dist/Menu Tidy Preview.app" --args --preview-ui
```

缺少权限的模拟场景追加 `--preview-permissions`。预览只能证明布局、可访问控件、过滤与模拟状态变化，不能证明第三方原生图标隐藏、原生菜单操作、权限批准、崩溃恢复或多显示器兼容性。正式应用没有被本轮预览替换。

本机截图、UI 检查记录和完整检查日志保存在 `.local/interaction-redesign-2026-09-29/`；其中修改前截图包含本机真实应用名称，不纳入公开仓库。该目录的 `REVIEW.md` 记录实际截图步骤与检查结果。

后续真实设备验证应覆盖：三项选择及重试往返；同应用多个图标共享开关；操作中改选与停止；应用退出再启动；普通托盘与显示全部；权限撤销与恢复；普通菜单排除是否影响实际远程状态栏图标。不能把历史版本或模拟数据的成功视为这些场景已经验收。
