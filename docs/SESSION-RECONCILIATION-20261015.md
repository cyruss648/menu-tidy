# 锁屏暂停与解锁补偿

版本：0.6.14，构建 70。设备验收与公开发布结果分别记录，源码检查不替代实机验收。

## 原因与行为

旧版本的周期补偿未区分锁屏与普通未知状态，锁屏下的 AX 可见性读取会进入普通失败路径。后台执行“应用全部待处理”还会为已保存的选择再次创建持久化草稿。

现在锁屏、会话失活、屏幕或系统休眠时暂停维护任务；新的启动、周期补偿、自动重连、被动采集和扫描发布均受当前桌面状态约束。WindowServer 会话在启动、通知和工作边界重新读取；会话不可用时仅有每三秒一次的轻量会话探测，不执行 AX 扫描或分类写入。

解锁后保留两秒稳定窗口，合并唤醒与解锁通知，只刷新一次当前菜单栏，再按当前补偿开关处理未完成项。托盘或其他工作尚未结束时顺延；关闭周期补偿且没有待执行的启动补偿时只刷新，不自动应用。下一周期从本轮恢复后重新计算，避免启动、解锁与周期补偿相邻执行。

扫描与应用带会话代次，跨越锁屏的结果不能发布或确认。锁屏打断批量写入时，等待每个尚未确认目标恢复，已确认的目标保留。恢复日志错误仍保留，不能因锁屏而隐藏真正的恢复失败。

自动补偿复用既有选择和批量队列，不新建用户草稿。用户实际更改产生的草稿、更新的选择和无关离线草稿继续保留，仅在目标得到正面确认后消费匹配记录。

## 系统信号与边界

会话和休眠通知通过 NSWorkspace 的 notificationCenter 接收；查询使用 CGSessionCopyCurrentDictionary、公开会话属性和当前显示器休眠状态。锁屏补充信号为本机 WindowServer 的 CGSSessionScreenIsLocked 属性与 com.apple.screenIsLocked / screenIsUnlocked 通知。这些锁屏补充信号不是 Apple 对所有系统版本的稳定兼容承诺；保留会话不可用时的保守处理，并用实机验收当前系统。

Apple 接口依据：[会话失活通知](https://developer.apple.com/documentation/appkit/nsworkspace/sessiondidresignactivenotification)、[会话重新激活](https://developer.apple.com/documentation/appkit/nsworkspace/sessiondidbecomeactivenotification)、[WindowServer 会话查询](https://developer.apple.com/documentation/coregraphics/cgsessioncopycurrentdictionary())、[会话属性](https://developer.apple.com/documentation/coregraphics/window-server-session-properties)。不修改系统锁屏、认证或隐私设置。

## 隔离与实机验证

完整检查通过 509 项核心 Swift 测试、90 项应用集成测试（新增 14 项会话相关测试）、96 项 Python 回归，以及 warnings-as-errors 构建。新增回归覆盖初始锁屏、超过旧截止时间、扫描中锁屏、写入后中断与逐项恢复、已确认同批项保留、托盘忙碌、重复通知、再次锁屏、启动补偿旧回调、关闭开关、真实用户选择与无关离线草稿保留、停止后的迟到事件。

在 macOS 27.0.1 Apple Silicon 上，已安装沿用正式签名身份的 0.6.14（70）候选包：

- 先正常恢复 Atoll、Clash 常驻，再取消两次隐藏操作，保留两条真实未完成选择和两条用户草稿，分类意图仍为收起后隐藏。
- 短暂锁屏后，系统在数秒内解锁；应用收到暂停与恢复事件，稳定窗口后自动刷新并补偿两项。两个原生目标共用一次偏好写入，分别确认隐藏成功，最终待处理与持久化草稿为 0；没有点击应用或重试，也没有手工删草稿。
- 原分类、规则、草稿三组数据与测试前一致。再次短暂锁屏后的恢复刷新没有重复补偿已确认项。
- 最初两次长锁屏尝试被自动解锁打断，原始失败观察保留。用户暂停自动解锁后，应用从 15:50:07.544 起保持暂停；15:55:19 仍读到系统锁定状态，共 311.5 秒。完整暂停日志内没有新的扫描、分类应用或原生批量写入；三组保存数据不变，草稿保持为 0。会话探测样本覆盖其中 64.2 秒，完整暂停时长另由应用事件与仍锁定的系统回读确认，不将两类证据混为连续采样。
- 用户随后于 16:35:34 解锁。应用等待 2.201 秒，只发起一次恢复刷新，并检查本轮补偿项为 0。界面中待处理与失败按钮均禁用，Atoll 与 Clash 各显示一行；未点击应用或重试。
- 恢复测试时临时关闭的启动补偿，保持后台补偿开启、间隔五分钟。正常退出后确认无应用进程，四类恢复日志均清空，分类、规则与草稿三组数据和测试前一致，持久化草稿为 0。候选包源码指纹未改变。

原始偏好、恢复日志、失败观察证据和签名材料留在忽略的本地目录，不随源码发布。
