# 设置页紧凑布局验收

## 范围与根因

目标版本：0.7.28（build 104）。

0.7.26 为避免状态插入导致滚动跳动，给软件更新的状态、等待说明、错误信息分别预留两行，即使透明也参与布局。正常状态下叠加出多余空白。图标管理行则固定保留 18 pt 标题、5 pt 间距、30 pt 说明和上下各 13 pt 内边距，单行共 79 pt；正常项目重复显示页面已有的“更改后自动处理”说明。

## 修改

- 图标管理行改为 48 pt：34 pt 内容区加上下各 7 pt 内边距。正常项目名称居中；实际所有者不同、处理进度、待应用、系统保留、未发现、分组不一致和错误才显示单行说明。
- 保留原字号、30 pt 图标、三项选择按钮和重试/重新连接入口。长错误保留完整悬停提示、辅助功能文案及原有处理入口。
- 更新状态共用两行：第一行显示结果，第二行按错误、延迟后的等待说明、最近检查时间的优先级展示。真实失败仍有警示颜色和图标。
- 更新详情浮层显示完整状态、检查时间、等待原因和错误，不增加页面高度；短活动仍延迟 350 ms 显示。
