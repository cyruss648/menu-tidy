## 自动测试覆盖范围

`swift test` 中的 18 个测试覆盖：

- 可见性初始状态、展开／收起切换、幂等操作、整理期间阻止收起、完成整理后保持展开，以及过期完成事件。
- 自动收起延时边界、有效与非有限数值处理、每一种交互暂停条件和禁用状态。
- 带刘海右侧区域的分隔项宽度、无右侧区域时的回退、紧张空间、异常几何值，以及旧版和新版布局的上下界。

以下项目需要实机证据：第三方图标是否真正消失、右侧图标和开关是否保留、展开后是否能操作目标菜单、拖动与位置持久化、登录项、退出恢复、系统版本差异、刘海屏和多显示器兼容性。

## 已知限制记录

- 自动收起只依据鼠标位置、按键状态与 Menu Tidy 自身窗口／菜单状态，不能识别所有第三方下拉菜单。
- macOS 27 的布局分支采用公开 AppKit 屏幕几何信息；这条代码路径本身不是兼容性证明。
- 多显示器、空间不足以及无法读取菜单栏本地窗口位置的情形必须单独记录，不能从单屏成功推断。
- 正常验收只运行一个菜单栏整理器。Barbee、Bartender、Ice 或另一个 Menu Tidy 实例同时运行时的结果不作为单独运行的通过证据。
- 演示模式图标属于本应用；即使演示成功，A06 和 A07 仍需使用真实第三方应用完成。
